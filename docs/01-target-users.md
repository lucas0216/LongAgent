# 01 · 目标用户

## 核心用户定义

> **用过对话 AI（ChatGPT / 豆包 / 元宝 / 通义 / 文心一言）但从没体验过本地 Agent 优势的中国用户。**

## 用户画像

### 主画像 P1：办公小白

| 维度 | 描述 |
|---|---|
| 年龄 | 25-40 |
| 职业 | 行政、HR、运营、市场、文员、财务助理 |
| 城市 | 一二三线均有 |
| 设备 | Windows 笔记本，8-16GB 内存，无独显或入门集显 |
| AI 经验 | 用过豆包/元宝/ChatGPT 网页版至少 3 个月，每周 5+ 次 |
| 技术水平 | 会装软件，不懂 API、命令行、git；会用 Excel 但不会写公式（或只会简单的）|
| 付费意愿 | 习惯了月付订阅（视频会员、网盘、WPS），¥19-39/月可接受 |

**关键特征**：
- 已经被 AI 教育过，知道 AI 能干嘛
- 但每天还在重复"复制粘贴 → AI 处理 → 复制回去"的循环
- 工作里大量时间花在文件处理（命名、整理、转格式、改内容）

## 明确排除的非目标用户

| 用户类型 | 为什么不是 | 给他们用什么 |
|---|---|---|
| 程序员、IT 工程师 | 偏好命令行、想要可编程 | Claude Code / Cursor / Cherry Studio |
| AI 极客、模型爱好者 | 喜欢自配多模型、玩 prompt | Cherry Studio / NextChat / LM Studio |
| 中老年完全不会用电脑 | 连"装软件"都困难 | 等 v2.0 的极简模式或不做 |
| 企业用户 | 需要私有化、合规、SSO | 等 v2.0 企业版或不做 |
| Mac 重度用户 | MVP 不做 Mac | v1.5 加入 |

## 用户的真实场景（高频痛点）

### 场景 A：办公文档处理（P1 主场景）

**张姐，36 岁，HR 主管，Win 笔记本 16GB**

**当前痛点**：
- 每月底要做考勤报表，从打卡机导出 .xlsx，要手工对每个员工的请假记录
- 经常要批量改文件名（"张三-简历.pdf" 改成 "应聘-技术岗-张三.pdf"）
- 周报要从一堆会议纪要 .docx 里提取她负责的事项
- 收到一堆截图（员工反馈、合同照片），要手工分类

**用 AI 的现状**：
- 偶尔把内容贴到豆包问问，但**没法批量**
- Excel 公式问豆包，照抄一遍
- 大部分时间还是手工

**LongAgent 帮她解决**：
- 拖一文件夹截图 → "按内容分类到不同文件夹"
- 拖打卡机 Excel → "生成本月各部门请假统计表"
- 拖一组会议纪要 → "提取我（HR）相关的待办，做成 todo 清单"

### 场景 B：内容创作工作流（P3 主场景）

**小林，28 岁，自媒体博主**

**当前痛点**：
- 写公众号要先看一堆素材（PDF、网页截图、视频字幕）
- 写完文章要做配图、写摘要、做卡片、想标题
- 多平台分发（公众号、知乎、小红书）每个平台格式不一样

**LongAgent 帮她解决**：
- 拖一堆素材 → "总结这些素材的核心观点和关键数据"
- 文章写完 → "把这篇文章按小红书风格改写（emoji + 短句 + 分段）"
- 把改好的输出成 Markdown / Word 直接发布

### 场景 C：学习与笔记（P2 主场景）

**小王，研一学生**

**当前痛点**：
- 一周读 5-10 篇英文论文，看完就忘
- 笔记散在 Notion / OneNote / Word / 微信收藏
- 期末要复习，找不到当时记的东西

**LongAgent 帮他解决**：
- 拖论文 PDF → "用中文总结核心贡献和 3 个关键实验"
- 拖一整学期的笔记文件夹 → 建本地知识库
- 期末 → "我笔记里关于强化学习的内容有哪些？"

## 用户研究：他们的"AI 使用进化路径"

```
未用过 AI
   ↓
听说过 ChatGPT
   ↓
注册账号，问几个问题（豆包/元宝是国内最大入口）
   ↓
养成日常使用习惯（一周 5+ 次）
   ↓ ← 这里是我们的目标用户
意识到痛点："为什么每次要复制粘贴？AI 能不能直接帮我？"
   ↓
开始搜索："AI 桌面助手"、"AI 文件处理"、"Agent"
   ↓
看到 Marvis（太重）、Cherry Studio（要配 API Key）
   ↓ 或
看到我们 → 留下来
```

**关键洞察**：用户**已经准备好了**，需求是真实的。他们只是没找到对的工具。
