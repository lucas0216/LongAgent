**我们的位置**：Task-first × 普通用户象限，**目前是空的**。

## 重点竞品逐个拆解

### 🍒 Cherry Studio（最大间接竞品）

**它是什么**：开源的多模型聊天客户端，BYOK 模式

**它的优势**：
- 多模型聚合（300+）、知识库、绘图、翻译、MCP、Claude Skills、硬件加速 OCR
- 开源免费、社区活跃
- 国产、中文友好

**它的短板**：
- **必须配 API Key**：小白第一关就死
- **Chat-first**：核心还是聊天框
- **功能太多**：小白看到劝退
- **知识库效果一般**（实测反馈）
- **没有透明的 Agent 执行流**

**我们 vs Cherry Studio**：

| 维度 | Cherry Studio | LongAgent |
|---|---|---|
| 用户群 | 极客 / AI 爱好者 | 小白 / 办公族 |
| 第一次打开 | 配置 API Key | 立即可用（本地模型）|
| 主交互 | 聊天框 | 拖文件 + 场景卡片 |
| 心智 | "我的 AI 工作台" | "AI 帮我搞定" |
| 产物 | 对话历史 | 实际文件 |
| 模型选择 | 用户选 | AI 自动路由 |
| 配置项 | 几十个 | 极少 |
| 学习曲线 | 中（多功能熟悉）| 极低（场景驱动）|

**差异化电梯陈述**：
> Cherry Studio 是给 AI 老炮的瑞士军刀，LongAgent 是给小白的智能信封——你把文件丢进来，它处理好交还给你。

### 🤖 腾讯 Marvis

**它是什么**：腾讯应用宝团队 2026/5/21 上线的 OS 级 AI 助手

**它的优势**：
- 1 主 Agent + 6 子 Agent 协作（文件/计算机/应用/浏览器/搜索）
- 每天免费送 1000 万 token
- 跨端（Win/Mac/Android）
- 本地隐私模式

**它的短板**（已实测确认）：
- **GUI 操作极慢**：微博签到要 3 分钟（每步截图分析）
- **首答即错**：信息推理偏差大、价格过时
- **任务半截而废**：系统设置只能"找到入口"，关键步骤手动
- **App 自动化是假的**：很多 App 操作实测是绕到网页搜索
- **隐私模式硬件门槛逆天**：16 核 CPU + 32GB 内存 + 16GB 显存 + 35GB SSD
- **常规模式仍需 16GB 内存**：低配用不动
- **全盘扫描的黑盒恐惧**：缺可视化"AI 看到了什么"

**我们 vs Marvis**：

| 维度 | Marvis | LongAgent |
|---|---|---|
| 范围 | OS 级（全能）| 文件场景（聚焦）|
| 硬件门槛 | 16GB+ 内存才稳 | 8GB 能跑 |
| GUI 自动化 | 主打但做不好 | 不做（v1.5 仅白名单）|
| 速度 | 3 分钟级 | 5-30 秒 |
| 可靠性 | ~50% | 95%+（窄场景）|
| 体积 | 重 | < 100MB |
| 隐私 | 隐私模式硬件门槛逆天 | 默认本地，门槛低 |

**差异化电梯陈述**：
> Marvis 想做 AI 操作系统但每件事都做一半；我们只做"动文件"这一件事，但做到秒级 100% 完成。

### 🥟 豆包桌面版 / 元宝桌面版 / 通义桌面版

**它们是什么**：大厂自家对话 AI 的桌面壳

**优势**：
- 大厂背书、品牌信任
- 模型最新最强（豆包用字节自家、元宝用混元）
- 渠道完整（应用商店、微信入口）

**短板**：
- **仍然是 chat-first**：本质是网页版套壳 + 输入法增强
- **几乎没有本地文件能力**：上传文件 ≠ 操作文件
- **没有 Agent 范式**：用完即没，没有任务概念
- **大厂的不可避免：边缘场景不重视**

**我们 vs 大厂对话 AI**：

| 维度 | 大厂对话 AI | LongAgent |
|---|---|---|
| 模型能力 | 最强 | 用云端 API 接近 |
| 品牌信任 | ⭐⭐⭐⭐⭐ | 0 起步 |
| 本地文件 | ❌ 仅上传 | ✅ 完整读写 |
| Agent 范式 | ❌ 仅 Chat | ✅ 完整 |
| 产物管理 | ❌ 对话历史 | ✅ 文件归档 |
| 离线/隐私 | ❌ 必须联网 | ✅ 本地模式 |
| 体积/内存 | 100MB+/300MB+ | 30MB/200MB |

**差异化电梯陈述**：
> 大厂对话 AI 让你"问 AI"，LongAgent 让你"让 AI 做"。

### 🛠 Claude Code / Cursor / Aider

**它们是什么**：开发者向 Agent 编程工具

**与我们的关系**：**不竞争，但是灵感来源**

我们要把 Claude Code 那套 **"透明 Agent 范式 + 工具调用 + 文件操作"** 的核心心智，**剥离掉代码场景**，**包装上小白能理解的 UI**。

### 🍒 LM Studio / Jan / Msty

**它们是什么**：纯本地推理的 GUI 客户端

**短板**：
- 极客向，要选模型、配参数
- 仍是 chat-first
- 没有 Agent / 工具使用能力

**与我们的关系**：用户重叠极少（他们的用户已经懂模型管理）

## 四维度差异化矩阵

把我们和主要竞品放在四个关键维度上：

| 产品 | 小白友好 | 文件能力 | Agent 范式 | 隐私（本地）|
|---|---|---|---|---|
| Cherry Studio | ⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐ |
| Marvis | ⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐（硬件门槛高）|
| 豆包桌面版 | ⭐⭐⭐⭐⭐ | ⭐ | ⭐ | ⭐ |
| 元宝桌面版 | ⭐⭐⭐⭐⭐ | ⭐ | ⭐ | ⭐ |
| Claude Code | ⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐ |
| **LongAgent** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |

**我们的独有定位**：**唯一同时拿满小白友好 + 文件能力 + Agent + 隐私**的产品。

## 差异化的 4 个"反向打法"

1. **反"多"**：不拼模型数量。预设 3 个（本地 + Flash + Pro），AI 自动路由
2. **反"广"**：不做全家桶。只做"动文件"，做到极致
3. **反"开放"**：不让用户自定义。预设场景全部最优化
4. **反"对话"**：不是 chat-first。首屏是"拖文件 + 场景卡片"

## 风险：可能被超车的方向

| 风险 | 概率 | 应对 |
|---|---|---|
| 大厂（字节/腾讯）做小白版 Agent | 高 | 速度 + 隐私故事 + 社区口碑 |
| Cherry Studio 加引导模式做小白版 | 中 | 我们的产品形态更聚焦，难以 follow |
| Marvis 优化变快变准 | 中 | 我们的"窄场景做透"在 reliability 上仍领先 |
| 模型成本继续暴跌，BYOK 不再是门槛 | 中 | 提前准备 BYOK 升级路径 |
| 国家政策变化要求所有 AI 服务备案 | 中-高 | L1 用国产合规模型，L3 走 BYOK 转嫁 |

## 总结：我们的核心差异化

> **唯一一款让"用过 ChatGPT 但没玩过 Agent"的小白，30 秒内体验到本地 Agent 优势的桌面工具。**

不与大厂正面打"全能 AI"，不与极客抢"自定义工作台"，**精准切走他们都看不见或不愿做的细分市场**。
