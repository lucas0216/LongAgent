# 03 · MVP 功能范围

## MVP 目标

> **4 个月内，做出一个能让小白 90 秒内体验到"AI 帮我动文件"差异化价值的 Windows 桌面应用，开始小范围验证。**

## 范围管理原则

- **P0**：必须做，缺了就不是这个产品
- **P1**：应该做，但可以延后到 v1.1
- **P2**：明确不做（MVP 不做，但可能 v1.5+ 做）
- **❌**：永不做或方向性否决

## P0 功能（MVP 必做）

### F1. 拖拽文件触发

**用户故事**：作为小白，我把任意文件拖到 App 窗口，AI 立即识别文件并主动问"要我做什么？"

**验收标准**：
- [ ] 支持拖拽单个/多个文件、整个文件夹
- [ ] 支持的文件类型：PDF, DOCX, XLSX, PPTX, TXT, MD, JPG, PNG, ZIP
- [ ] 拖入后 < 500ms 显示文件预览（缩略图 + 元信息）
- [ ] AI 在 < 2s 内基于文件类型 + 内容主动提出 2-3 个建议任务（如 "总结 PDF / 提取要点 / 翻译"）
- [ ] 用户可点击建议任务，也可自己输入
- [ ] 大文件（> 50MB）有进度提示
- [ ] 文件类型不支持时给出明确提示，不会卡死

### F2. 文件读取与解析

**用户故事**：AI 能读懂我提供的文件内容，并基于内容回答问题。

**验收标准**：
- [ ] PDF：支持文本 PDF（pdfplumber）+ 扫描件 OCR（RapidOCR）
- [ ] Word（.docx）：保留段落、表格、标题层级
- [ ] Excel（.xlsx）：按 sheet 解析，保留表格结构
- [ ] PowerPoint（.pptx）：按 slide 解析
- [ ] 图片（jpg/png/webp）：OCR 提取文字
- [ ] 解析失败有清晰的错误提示
- [ ] 单文件解析 < 30s（普通文件 < 5s）

### F3. 文档生成与落盘

**用户故事**：AI 帮我做的产物（摘要、邮件、报告）直接保存为我能用的文件。

**验收标准**：
- [ ] 支持生成：`.docx`（Word）、`.xlsx`（Excel）、`.md`（Markdown）、`.txt`（纯文本）、`.pptx` **延后到 P1**
- [ ] 默认保存到桌面 `LongAgent 产物/` 文件夹
- [ ] 文件名自动生成（基于内容 + 时间戳），用户可改
- [ ] 生成后在 UI 显示"打开文件"和"打开所在文件夹"按钮
- [ ] 复杂格式（如带样式 Word、含公式 Excel）至少能基础格式化

### F4. 批量文件处理

**用户故事**：我有一堆文件需要批量重命名/分类/转格式。

**验收标准**：MVP 限定以下 3 个场景：
- [ ] **批量重命名**：用户拖文件夹 + 描述规则，AI 生成新名称，**先 dry-run 显示对照表，用户确认后再执行**
- [ ] **按内容分类**：用户拖文件夹，AI 识别每个文件内容，建议分类，用户确认后移动
- [ ] **格式转换**：PDF → DOCX、图片 → 文字（OCR + DOCX）、DOCX/PPTX → PDF
- [ ] 每个批量操作必须有 dry-run 预览
- [ ] 必须有"撤销"按钮（保留 24 小时回滚能力）
- [ ] 单批最多处理 200 个文件（超过提示分批）

### F5. 执行过程可视化（**差异化核心**）

**用户故事**：我能看见 AI 每一步在做什么，知道它没瞎搞我的电脑。

**验收标准**：
- [ ] 每个任务一个"执行流"组件，时间线样式展示
- [ ] 每步显示：动作图标（📖读取/✏️编辑/🧠思考/✅完成）+ 一句自然语言描述
- [ ] 实时流式更新（不是任务结束才一次展示）
- [ ] 可点击展开看详情（被读取的文件、模型的中间输出）
- [ ] 失败的步骤红色标记，并显示原因
- [ ] 用户可以**随时点暂停 / 中断**
- [ ] 任务完成有明显的成功状态

### F6. 一键撤销 / 时间旅行

**用户故事**：AI 改完不是我想要的，我能一键恢复。

**验收标准**：
- [ ] 所有修改文件、移动文件、重命名的操作都创建"快照"
- [ ] 任务列表里每个任务旁有"撤销"按钮
- [ ] 撤销只回滚该任务的操作，不影响其他任务
- [ ] 撤销操作不可再撤销（一级 redo 即可，不做时间旅行复杂版）
- [ ] 快照保留 7 天后自动清理（防磁盘膨胀）

### F7. 首页场景卡片（**Aha Moment 载体**）

**用户故事**：我打开 App 第一眼就知道这个工具能干嘛。

**验收标准**：
- [ ] 首页展示 4-6 个场景卡片，覆盖主画像 P1 高频场景
- [ ] 推荐场景（MVP 上线时）：
  1. 📂 "把这批截图按内容分类好"
  2. 📄 "读完这个 PDF 给我写一份 1 页摘要"
  3. 📊 "把这个 Excel 数据做成图表"
  4. ✉️ "根据这份会议纪要写跟进邮件"
  5. 🔁 "批量重命名这些文件"
  6. 🌐 "把这个 PDF 翻译成中文/英文"
- [ ] 卡片点击后进入引导式对话，prompt 已预填，用户只需拖文件
- [ ] 每个卡片有"试一下示例"按钮（用 demo 文件演示，不需要用户准备数据）

### F8. 本地模型集成 + 智能路由

**用户故事**：我不用懂模型，AI 自己选最合适的；隐私敏感的事走本地。

**验收标准**：
- [ ] 内置 Ollama runtime
- [ ] 启动时按硬件自动下载推荐模型（8GB 内存 → 1.5B；16GB+ → 4B）
- [ ] 路由器规则：
  - 简单任务（翻译/总结/改名）→ 本地
  - 复杂任务（规划/推理）→ 云端 V4 Flash
  - 极复杂（多文件/长上下文）→ 云端 V4 Pro
  - 用户开"隐私模式" → 强制本地
- [ ] UI 上只露**一个开关**：「🔒 数据安全模式」
- [ ] 状态栏微妙提示当前模式（"使用云端 AI（更聪明）" / "使用本地 AI（数据不出电脑）"）

### F9. 用户配额与计费（基础版）

**用户故事**：免费层能用，但有限制；想多用要付费。

**验收标准**：
- [ ] L1 免费层：每天 20 次云端调用 + 无限本地
- [ ] 配额到 80% 时友好提示
- [ ] 配额耗尽自动降级到本地（不阻塞使用）
- [ ] L2 订阅 / L3 BYOK 在 v1.0 上线时**可以是 stub**（"敬请期待"），但要预留入口
- [ ] 计费数据本地记录 + 每日上报到后端（如果接入后端）

### F10. 隐私与安全基础

**用户故事**：我担心 AI 乱看我电脑。

**验收标准**：
- [ ] App 启动时引导用户选择"可访问目录"（默认仅桌面/下载）
- [ ] 任何对其他目录的访问要弹权限确认
- [ ] **首次启动展示"我们承诺"页**：列明数据流向、本地优先承诺、不收集行为数据
- [ ] 设置页有"我的数据"面板：可看到 AI 索引了哪些文件、可一键清除
- [ ] API Key（L3 模式）存储在 OS Keychain，不落到任何配置文件

## P1 功能（v1.1 上线，MVP 不做）

### F11. 本地知识库

- 拖文件夹建知识库
- 向量化（BGE-M3）+ 全文搜索混合
- 对知识库提问，引用原文
- 增量索引

### F12. PPTX 生成

- 简单模板的 PPTX 生成
- 复杂样式延后

### F13. 历史对话与任务管理

- 任务列表、收藏、归档
- 跨任务搜索

### F14. 定时任务 / 文件夹监控

- 设置定时执行（如"每周一汇总周报"）
- 监控某文件夹有新文件自动处理

### F15. 智能命名补全（小白福利）

- 用户没说明白时，AI 主动追问澄清（一次性最多 1 个问题）

## ❌ 明确不做（永不做或方向性否决）

| 功能 | 原因 |
|---|---|
| 多 Agent 编排 UI | 不暴露 Agent 概念给小白 |
| 自定义 prompt 模板市场 | 走 Cherry Studio 路线 |
| 模型管理面板（手动选模型）| AI 自动路由，不让用户选 |
| 屏幕理解 / OCR 全屏识别 | Marvis 主场，且小白不需要 |
| 替用户发邮件 / 发消息 | 不可逆操作的红线 |
| 自动执行 shell / Python 脚本 | 小白完全无法判断安全性 |
| 多设备同步 | 增加云依赖、违背隐私定位 |
| 浏览器插件 | MVP 不分散精力 |
| 移动端 | 完全偏离桌面定位 |

## 验收的"Aha Moment 指标"

MVP 上线时，必须达到以下数据：

| 指标 | 目标 |
|---|---|
| 新用户从打开到完成首个任务的中位耗时 | < 90 秒 |
| 新用户首次任务成功率 | > 80% |
| 新用户 7 日留存 | > 30% |
| 平均每个 DAU 每天完成任务数 | > 2 |

## 范围保护机制

每次有人提议"加 X 功能"时，问 3 个问题：

1. **它是否帮我们 90 秒达成 Aha Moment？** → 是 P0 候选
2. **它是否能用同样精力换更高的 Aha Moment？** → 用它替换某个 P0
3. **它是否只是"看起来酷"？** → 拒绝
