# 04 · 核心用户流程

## 设计原则

1. **90 秒内必须出现 Aha Moment**（用户感受到"这跟 ChatGPT 不一样"的瞬间）
2. **任何高频操作 ≤ 3 次点击**
3. **小白看见的术语清单 ≤ 10 个**（"任务"、"产物"、"撤销"、"本地"、"安全模式" 等通俗词）
4. **每一步都可后退、可中断、可撤销**

## 流程 1：新用户首次启动（Onboarding）

### 目标

让用户在 **90 秒内**完成一次完整任务并体验 Aha Moment。

### 关键设计

**❌ 不要这样**：
- 弹长篇引导教程
- 让用户先注册账号
- 让用户先配置（API Key、模型、目录权限全弹一遍）

**✅ 要这样**：
- 极简初始化（< 30 秒）
- 直接进首页，带预填 demo
- 权限按需弹（用到某目录才申请）

### 流程详解

```
[启动 App]
   ↓ < 3s
[欢迎页：1 屏，3 句话]
   "你的 AI 桌面助手"
   "把文件丢给它，它会帮你处理"
   "完全免费，本地优先"
   [按钮：开始使用]
   ↓
[硬件检测 + 本地模型推荐]
   "我们检测到你的电脑配置：16GB 内存"
   "推荐使用 Qwen3-4B（约 2.5GB）"
   [按钮：自动下载（默认）] [跳过先用云端]
   ↓ 模型在后台下载
[首页：场景卡片墙]
   显示 4-6 个场景，每个都有"试一下示例"
   ↓
[用户点 "PDF 摘要" 卡片的"试一下示例"]
   App 用内置 demo PDF 跑一次完整流程
   ↓
[执行流可视化]
   📖 正在读取 sample.pdf
   🧠 AI 正在分析内容
   ✏️ 正在生成摘要文档
   ✅ 已保存到桌面 / LongAgent 产物 / sample 摘要.docx
   ↓
[完成态]
   显示生成的文件预览
   [按钮：打开文件] [打开文件夹] [试试别的]
   ↓
   🎉 Aha Moment 完成
```

**关键时间预算**：
- 启动到首页：3-5 秒（背景下载模型，不阻塞）
- 用户点示例到看到执行流：< 2 秒
- 整个 demo 任务完成：< 30 秒（用 Flash 模型）
- **总用户感知时长：< 90 秒**

### Aha Moment 验证清单

用户在这 90 秒里必须体验到：

- [ ] 看到 AI "正在读取你的文件"（视觉冲击）
- [ ] 看到 AI 一步一步在做事（透明感）
- [ ] 看到产物**真的出现在桌面上**（这是和 ChatGPT 最大的区别）
- [ ] 可以直接打开产物文件继续编辑

## 流程 2：拖文件触发任务（最高频）

### 入口

任意时刻把文件拖到 App 窗口（即使在首页、设置页、其他任务页）。

### 流程

```
[用户拖入文件]
   ↓ < 500ms
[文件浮层出现]
   - 缩略图 / 图标
   - 文件名、类型、大小
   - "等待你的指令..." 输入框
   - 下方 3 个 AI 主动建议（基于文件类型）
   ↓
[场景 A：用户点了 AI 建议]
   → 直接进入执行流
[场景 B：用户自己输入]
   → AI 理解后进入执行流
   ↓
[执行流可视化]
   ...
   ↓
[完成]
```

### 多文件拖拽

- 单一类型多文件 → 默认"批量处理"建议
- 混合类型 → 默认"整理 / 分类"建议
- 整个文件夹 → 默认"建知识库 / 内容分类"建议

## 流程 3：任务对话（替代纯聊天）

### 与 ChatGPT 风格的关键差异

| 维度 | ChatGPT | LongAgent |
|---|---|---|
| 主体 | 对话框 | "执行流" + 对话 |
| 用户输入位置 | 中央输入框 | 底部，附带"拖文件"按钮 |
| AI 输出形态 | 文本流 | 文本流 + 工具调用步骤 + 产物卡片 |
| 历史 | 线性 | 任务式（每个任务一个会话 + 产物归档）|

### 任务页结构

```
┌──────────────────────────────────────────┐
│  [任务标题: AI 自动命名]   [⏸暂停] [⤴撤销] │
├──────────────────────────────────────────┤
│                                          │
│  [执行流时间线]                          │
│   📖 已读取 报销单.xlsx                  │
│   🧠 已分析数据                          │
│   ✏️ 正在生成 报销汇总.docx              │
│                                          │
│  [产物卡片]                              │
│   📄 报销汇总.docx                       │
│      [预览] [打开] [打开文件夹]          │
│                                          │
│  [继续对话区]                            │
│   你: 把表格的标题字号改大点             │
│   AI: 好的，正在调整...                  │
│                                          │
├──────────────────────────────────────────┤
│ [📎] [_____输入框: 继续对话或拖文件_____] │
└──────────────────────────────────────────┘
```

### 任务的生命周期

```
新建（拖文件 / 选场景 / 点新任务按钮）
   ↓
进行中（流式执行、可暂停 / 中断）
   ↓
完成（产物落盘、可继续对话精修）
   ↓
归档（7 天后自动归档，但任务保留可查）
   ↓
（任务列表可搜索、可手动删除）
```

## 流程 4：撤销 / 时间旅行

### 触发场景

- 任务页右上角的 "⤴撤销" 按钮
- 任务列表里每个任务旁的撤销按钮
- 全局快捷键 `Ctrl+Z`（仅在任务页）

### 流程

```
[用户点撤销]
   ↓
[确认弹窗]
   "这会回滚以下操作："
   "  • 移动 5 个文件到「2026 截图」文件夹"
   "  • 重命名 3 个文件"
   "  • 删除 报销汇总.docx"
   "你确定吗？"
   [取消] [撤销]
   ↓
[执行撤销]
   - 文件操作反向回滚
   - 产物文件移到回收站（不直接删）
   - 数据库标记任务为 "已撤销"
   ↓
[显示完成]
   "已撤销，所有文件已恢复"
```

### 撤销保护规则

- 撤销可在 **7 天内**操作
- 已撤销的任务不能再撤销（避免循环）
- 撤销后的任务在历史里灰色显示
- 用户主动删除的文件**不进入撤销**（系统回收站负责）

## 流程 5：本地模式切换

### 入口

- 状态栏的"安全模式"开关
- 设置 → 数据安全
- 任务进行中可临时切换（影响下一次调用）

### 流程

```
[默认状态: 智能路由模式]
   状态栏: 🤖 智能模式 (云端 + 本地)
   ↓
[用户点击开关]
   ↓
[确认弹窗]
   "切换到本地模式后："
   "  ✅ 所有数据不会发送到云端"
   "  ✅ 断网也能使用"
   "  ⚠️ AI 能力略弱，复杂任务可能失败"
   [取消] [切换]
   ↓
[切换完成]
   状态栏: 🔒 本地模式 (数据不出电脑)
```

### 隐含规则（用户不需要理解）

- 触发以下情况**自动切换本地**（不询问用户）：
  - 用户在文件名/内容里提到敏感词（身份证、合同、工资、银行卡）
  - 用户在标记为"敏感"的目录下操作
  - 配额耗尽

## 流程 6：付费转化（L1 → L2）

### 触发时机

**❌ 不要这样**：
- 进 App 就推付费
- 弹"升级开通会员"
- 限制大量基础功能

**✅ 要这样**：

| 时机 | 提示形式 | 文案 |
|---|---|---|
| 配额到 80% | 状态栏温和提示 | "今日免费额度还剩 4 次" |
| 配额耗尽 | 自动降级到本地 + 微弹 | "今日云端额度用完了。本地模式继续可用，或 [解锁无限] ¥29/月" |
| 任务卡在本地能力不足时 | 任务页内提示 | "这个任务用云端 AI 效果会更好。要不要试试？" |
| 第 7 / 30 天活跃 | 弹一次（且仅一次）感谢页 | "你已经用了 7 天，省下 N 小时。要不要升级解锁更多？" |

### 流程

```
[用户点击升级]
   ↓
[订阅页]
   - 三个 tier 对比
   - 突出 L2 月费 ¥29
   - 强调"随时取消"
   - 7 天试用（首次用户）
   ↓
[支付（微信 / 支付宝）]
   ↓
[支付完成]
   - 立刻解锁权限
   - 一封确认邮件
   - 回到原任务继续
```

## 流程 7：L3 高级模式（BYOK）

### 入口

- 设置 → 高级 → "我有自己的 API Key"
- 默认折叠，小白看不到

### 流程

```
[用户进入 BYOK 设置]
   ↓
[选择供应商]
   - 火山方舟 (推荐)
   - DeepSeek 官方
   - 阿里云百炼
   - 自定义（OpenAI 兼容）
   ↓
[填写信息]
   - API Key（OS Keychain 加密存储）
   - Base URL（可默认）
   - 模型选择（Pro / Flash）
   ↓
[测试连接]
   "正在测试..."
   "✅ 连接成功，本月余额: ¥XX.XX"
   ↓
[完成]
   现在所有云端调用使用你的 Key，不计入你的免费额度
```

## 错误流程（必须妥善处理的失败场景）

| 场景 | 应对 |
|---|---|
| 网络断了 | 自动切本地模型 + 顶部提示 "已切换到本地模式" |
| 云端 API 限流 | 切到备用供应商；再失败切本地 |
| 模型生成失败 | 重试 2 次；再失败显示原因 + 建议 |
| 文件解析失败 | 提示具体原因（密码加密 / 格式损坏） |
| 磁盘空间不足 | 提示并阻塞，给清理建议 |
| 文件被其他程序占用 | 提示用户关闭程序后重试 |
| API Key 无效 (L3) | 弹窗让用户重新输入 |
| 配额耗尽且本地模型未下载 | 阻塞 + 引导下载本地模型 |

## 用户故事映射（精简版）

```
作为小白用户
├─ 我想快速处理我的文件
│  ├─ 拖文件就能开始 (F1)
│  ├─ AI 主动提建议 (F1)
│  └─ 一键完成 (F2-F4)
├─ 我想看清 AI 在做什么
│  ├─ 每步都有图标和说明 (F5)
│  ├─ 可以暂停 (F5)
│  └─ 可以撤销 (F6)
├─ 我想免费试用
│  ├─ 不用注册 (Onboarding)
│  ├─ 不用配 Key (F8)
│  └─ 本地模型也好用 (F8)
└─ 我想知道我的数据安全
   ├─ 隐私模式一键切换 (流程 5)
   ├─ 看得见 AI 索引了什么 (F10)
   └─ 不上传不收集行为 (F10)
```
