# 08 · 商业模式与单元经济

## 模式概览

三层用户（L1/L2/L3）渐进式付费模型 — 详见 [ADR-0004](adr/0004-three-tier-model.md)

```
免费用户 ─ L1 ──→ 体验 Aha Moment ──→ 用爽了 ──→ L2 订阅
                                                  │
                                                  └→ 重度极客 ──→ L3 BYOK
```

## 三层用户详解

### L1 · 即开即用（免费）

**目标**：吸引下载、消除门槛、让用户体验差异化价值

| 项目 | 内容 |
|---|---|
| 价格 | ¥0 |
| 配置 | 零（不需要登录、不需要 API Key）|
| 本地模型 | ✅ 无限使用 |
| 云端额度 | 每天 **20 次** Flash / Pro 调用 |
| 可用功能 | 全部 P0 功能 |
| 限制 | 单次任务最多 5 次模型调用；单文件 < 50MB |
| 用户感知 | "免费桌面 AI 助手" |

**核心策略**：本地能力**永久免费**，云端是付费墙。

### L2 · 无限会员（订阅）

**目标**：变现主力，覆盖云端成本

| 项目 | 内容 |
|---|---|
| 价格 | **¥29/月** 或 ¥299/年（≈¥24.9/月）|
| 试用 | 首次用户 7 天免费试用 |
| 云端额度 | 无限（公平使用政策：每天 < 200 次）|
| 模型 | Pro 优先（更聪明）|
| 高级功能 | 知识库（P1）、定时任务（P1+）、产物云备份（v1.x）|
| 客服 | 优先邮件支持 |
| 用户感知 | "解锁 AI 全部能力" |

**支付方式**：微信支付、支付宝（国内）；Stripe（境外，v1.x）

### L3 · 极客模式（BYOK）

**目标**：让重度技术用户不亏，同时不占我们 token

| 项目 | 内容 |
|---|---|
| 价格 | ¥299 一次性买断 App License（永久）|
| API Key | 用户自己提供 |
| 自由度 | 可选任何供应商（火山/DeepSeek/阿里/OpenAI 等）|
| 模型选择 | 用户可看见并切换具体模型 |
| 限速 | 仅受用户自己的 API 限制 |
| 用户感知 | "完全自主，不被监控" |
| **隐藏在二级菜单**| 小白看不到这个选项（避免误导）|

**为什么是买断而非订阅**：
- 这类用户讨厌"按月订阅+自带 Key"的双重收费
- 一次性收费在心理上是"我买了软件"而非"我租了服务"
- 我们零变动成本（不出云端钱）

## 营销渠道与获客策略

### 主要渠道（按优先级）

#### 1. 内容营销：B 站 + 小红书

**核心格式**：30-60 秒短视频对比

模板：
- 标题："ChatGPT 做不到的 X 件事，这个 AI 桌面助手 30 秒搞定"
- 内容：对比演示（ChatGPT/豆包 vs LongAgent）
- CTA：评论区放下载链接

预算：早期 0 元（自己拍）→ 增长期与小博主合作（CPM ¥30-50）

#### 2. 公众号 + 知乎长文

**主题方向**：
- "为什么我从豆包桌面版换到了这个"
- "PDF 摘要的 N 种姿势"
- "AI 帮我整理 1 万张截图的故事"

#### 3. SEO

关键词：
- "AI 桌面助手"
- "AI 文件管理"
- "本地 AI 工具"
- "AI 整理截图"
- "AI 写报告"

#### 4. 应用商店

- 微软应用商店（Win 11 标配）
- 国内国产 App Store（华为/小米/腾讯应用宝）
- Mac App Store（v1.5）

### 不做的渠道

- ❌ 信息流广告（CAC 太高，> ¥100/用户）
- ❌ 搜索竞价（与"AI 工具"撞太多大厂）
- ❌ 应用商店刷榜
- ❌ 强制邀请好友解锁（口碑反噬）

## 单元经济（Unit Economics）

### 关键比率

| 指标 | 目标 | 备注 |
|---|---|---|
| 月用户成本（L1 平均）| ¥0.67 | 见 [07-成本](07-model-routing-cost.md)|
| 月用户成本（L2 平均）| ¥6-12 | 高频用户、Pro 占比更高 |
| L1 → L2 转化率 | 5-10% | 行业平均 3-8% |
| L2 ARPU | ¥25/月 | ¥29 月费扣支付通道费 |
| L2 LTV / 单用户 | ¥150-300 | 平均订阅 6-12 个月 |
| L1 CAC（内容营销）| < ¥5 | 主要靠口碑 |
| L2 CAC | < ¥15 | 通过 L1 转化 |
| **LTV / CAC** | **> 10** | 健康水平 |

### 不同 MAU 下的财务预测

| 阶段 | MAU | 付费用户（5%）| 月收入 | 月成本（云端）| 月毛利 |
|---|---|---|---|---|---|
| 试运营（M3-4）| 1,000 | 50 | ¥1,450 | ¥670 | ¥780 |
| 早期（M6）| 10,000 | 500 | ¥14,500 | ¥6,700 | ¥7,800 |
| 增长（M12）| 50,000 | 2,500 | ¥72,500 | ¥3.4 万 | ¥3.8 万 |
| 规模（M18）| 200,000 | 10,000 | ¥29 万 | ¥13.6 万 | ¥15.4 万 |
| 成熟（M24）| 500,000 | 25,000 | ¥72.5 万 | ¥34 万 | ¥38.5 万 |

**关键临界点**：MAU > 5,000 时毛利转正，足以支持 1-2 人团队全职运营。

## 防滥用机制

### L1 滥用场景

| 滥用 | 检测 | 应对 |
|---|---|---|
| 一人多机注册（绕配额）| 设备指纹 | 同指纹合并配额 |
| 脚本调用 | 行为模式 | Captcha → 限流 |
| 大文件爆破（吞 token）| 单调用 token > 50000 | 拒绝 + 提示 |
| 卖配额给他人 | 异地 IP + 异常模式 | 风控锁定 |

### L2 滥用场景

| 滥用 | 应对 |
|---|---|
| 单账号给多人用 | 设备指纹绑定（最多 3 台）|
| 高频远超公平使用 | 软提示 → 限速 → 客服联系 |
| 退款套利 | 7 天试用一次性，订阅退款人工审批 |

| 项目 | 责任 |
|---|---|
| 个人信息保护法 | 必须公开隐私政策、用户协议 |
| 数据出境 | L1/L2 数据**不出境**（用国产模型）|
| AI 生成内容标识 | 按 [生成式 AI 服务管理办法] 在产物加水印（可关）|
| 备案 | App 上架国内商店需备案 |
| 增值税 / 个税 | L2 收入开票 |
