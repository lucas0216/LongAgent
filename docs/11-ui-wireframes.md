# 11 · 核心页面 Wireframes

> 本文档定义 MVP 阶段 3 个核心页面的视觉布局、组件结构、状态机与交互细节。
> 配合 [03 MVP 范围](03-mvp-scope.md)、[04 用户流程](04-user-flows.md) 阅读。

## 设计原则

1. **任务即页面**：每个 Agent 任务一个 URL/路由，不是聊天会话
2. **拖文件是一等公民**：任何屏都可拖文件触发
3. **执行流可视化是杀手锏**：必须做到行业最佳
4. **小白看不到术语**：不用"Agent / 工具 / Prompt / Token"等词
5. **暗色优先**：MVP 仅暗色主题（V1.1 加亮色）

### 执行流步骤设计（差异化核心）

每一步是一个时间线节点，整体是垂直 timeline。

```
●─ 📖 已读取 财报2026Q1.pdf
│     14 页 · 28KB · 0.4s
│
●─ 🧠 AI 已分析关键数据
│     找到 3 个核心指标、5 段重要结论 · 6.2s
│     ▼ 详情（点击展开）
│        营收: 28.7 亿（同比 +18%）
│        利润: 4.2 亿（同比 +12%）
│        研发: 3.1 亿（同比 +6%）
│
●─ ✏️ 已生成 财报2026Q1 摘要.docx
│     1 页 · 6 段落 · 1.8s
│
●─ 💾 已保存到 桌面 / LongAgent 产物 /
│     位置: ~/Desktop/LongAgent 产物/2026-05-27 PDF摘要 - 财报2026Q1.docx
│
✅ 任务完成 · 总用时 28 秒
```

#### 步骤图标 → 颜色 → 含义

| 图标 | 颜色 | 步骤类型 |
|---|---|---|
| 📖 | sky-400 | 读取（文件、网页、数据库）|
| 🧠 | purple-400 | AI 思考/分析 |
| ✏️ | emerald-400 | 写入/编辑/生成 |
| 📊 | sky-400 | 数据处理/图表 |
| 🔁 | amber-400 | 批量操作 |
| 💾 | emerald-400 | 保存到磁盘 |
| ✅ | emerald-500 | 任务完成 |
| ⚠️ | amber-500 | 用户确认 / 需要决策 |
| ❌ | red-500 | 错误 / 失败 |
| ⏸ | neutral-500 | 已暂停 |

#### 状态指示器

```
●  已完成（实心圆 emerald-500）
○  未开始（空心圆 neutral-700）
●  进行中（实心圆 + 旁边 spinner ▲）
✗  失败（实心圆 red-500）
⏸  暂停（实心圆 neutral-500）
```

### 用户交互

| 操作 | 触发 | 结果 |
|---|---|---|
| 点 ⏸ 暂停 | 任务进行中 | Sidecar 接收 abort signal，当前步骤完成后停 |
| 点 ⤴ 撤销 | 任务有任何文件操作 | 弹确认窗，列举要回滚的操作 |
| 双击任务标题 | 任意时刻 | 进入编辑模式，改名 |
| 点击 ExecutionStep | 任意时刻 | 展开/收起详情 |
| 点击 ArtifactCard 文件名 | 完成后 | 用系统默认 App 打开 |
| 拖文件到 Composer | 任意时刻 | 文件 attach 到下一条消息 |
| 在 Composer 输入 | 完成后 | 继续在同一任务里追加指令（保留上下文）|
| 点击 AssistantMessage 里的"建议下一步" chip | 完成后 | 自动 prefill Composer |

## 状态机汇总

### 全局状态

```
启动
  ├─ 首次启动 → 引导页（"我们承诺..." 隐私页）→ 模型下载 → HomePage
  └─ 后续启动 → 直接 HomePage
                ↓
            HomePage
                ↓ (拖文件 / 选场景)
            TaskPage (执行中)
                ↓ (完成)
            TaskPage (完成态)
                ↓ (用户点"返回" 或 Logo)
            HomePage
```

### TaskPage 状态机

```
[pending] → [running] → [completed]
                    ↓
                [failed]
                    ↓ (用户点重试)
                [running]
                    
[running] → (用户点 ⏸) → [aborting] → [aborted]
[completed] → (用户点 ⤴) → [undoing] → [undone]
```

## 响应式与窗口尺寸

- **最小窗口**：800×600（小白旧笔记本）
- **默认**：1100×720
- **大屏**：≥ 1400×900，内容居中最大宽 1400

### 断点处理

| 宽度 | 变化 |
|---|---|
| ≥ 1100px | TaskPage 60/40 横向 SplitLayout |
| 900-1100px | TaskPage 65/35 横向 |
| < 900px | TaskPage 执行流折叠为底部抽屉，对话区全宽 |
| < 800px | 不支持，提示用户调大窗口 |
